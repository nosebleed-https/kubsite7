Как пользоваться сайтом

  1. В калькуляторе введите количество товара и выберите товар.
  2. Для тетради выберите количество листов, для папки — при необходимости отметьте застёжку.
  3. Стоимость заказа пересчитывается автоматически.
  4. В галерее нажимайте стрелки, чтобы переходить между страницами изображений.
  5. Пейджер под галереей показывает текущую страницу и общее количество страниц.
